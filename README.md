# Mythic Atlas — delivering a fixed scope, complete

**A project-management case study.** Mythic Atlas is an interactive browser map that places the world's mythology at real coordinates: kingdoms, gods and creatures where tradition puts them.

**[Full case study](https://arielzin33-creator.github.io/#project-3)**

![Mythic Atlas](https://arielzin33-creator.github.io/assets/projects/project-3.jpg)

## The problem

Mythology is tied to real places, Olympus over Greece and Asgard somewhere suitably northern, but there was no single explorable map that put it all at real coordinates.

## Scope & plan

- **A deliberately tight boundary:** browser only, no backend, no framework, so the whole project could be finished rather than half-built.
- **Content planned up front** as structured GeoJSON data: each kingdom, god and creature with its location and metadata.

## My role

Solo: scope, content planning and delivery.

## Key decision & risk

**Information density.** With enough entries on one map, markers turned into noise. Clustering fixes that, but set too aggressively it hides the content people came for, so the thresholds were tuned iteratively against what a user needs to see at each zoom level.

## Outcome

Delivered complete within the scope I set: a fully working interactive map, browsable end to end, with every planned layer finished.
